## 前言

本文如题，主要收录各种在获取到模型资源后可以开拓的方向的操作指南，会长期更新。本文作为演示例子的大多是从 SF6 里解包的人物模型。

## 一、转 vrm 模型

在导出为 vrm 模型之前，首先需要解决骨骼合并的问题。解包出的文件里，头、身体、头发是三个互相独立并带有自己骨骼的网格体。

### 合并骨骼

同一个项目相同的工作流下，不难设想这些骨骼本身的命名和嵌套是完全一致的，因此转移骨骼的工作其实不算麻烦。我个人倾向于从小骨骼合并到大骨骼的顺序，一般来说是把头和头发合并到身体的骨骼上面去。

![](IMG-20250620135334344.png)

只要将大骨骼上没有的部分挑选出来，附着到大骨骼的相同父级上就可以了。例如下图，比较面部和身体的骨骼，可以看出面部相较于身体，在 Head 骨骼下附加了大量面部的骨骼。我们需要把这部分骨骼合并到身体骨骼中。

![](IMG-20250620135334402.png)

下面以巴什的模型为例，进行合并骨骼的实际操作。

首先将所有骨骼<kbd>ctrl</kbd>+<kbd>J</kbd>合并，让它们在同一个 Armature 中，否则之后无法顺利设置父级关系。合并后，点开被合并的骨架，由于同名的节点会被自动重命名后缀，所以只需要找到没有被增加后缀的节点就能马上找到哪些是原骨骼中不存在的骨骼。

![](IMG-20250620135334429.png)

不难发现，需要迁移的内容包含：面部的 C_FaceRoot 和 C_Chin_HJ 骨骼及其子骨骼；头发的 C_Hair_Root 骨骼及其子骨骼。

切换到编辑模式，选中 C_Head 节点，按 <kbd>P</kbd> 分离骨骼为新骨架。此时可以得到两个独立的骨骼 C_FaceRoot 和 C_Chin_HJ 。在保持子选项收起的状态下选中这两个骨骼，再单击身体骨骼中的 C_Head，<kbd>ctrl</kbd>+<kbd>P</kbd>指定父级，选择 `保持偏移量`，即可成功合并。头发的 C_Hair_Root 处理方法同理。

处理完毕后，返回到物体模式，将所有属于面部和头发的网格体在修改器中的物体设置为身体的 Armature，模型的合并就完成了。

![](IMG-20250620135334459.png)

### 导出为 vrm 模型

使用 [VRM format]() 插件导出。在 Blender 的获取扩展中可直接联网搜索到，也可以点击前文链接跳转到 github 仓库查看。

导出之前需要打开 Humanoid 的列表，将必要的骨骼都填入。非必要的骨骼，只要模型有适配，也可以都填上。填写完毕后可以点击 `按vrm模型标准检查`，确认无误后就可以直接在导出中选择 vrm 格式和要导出的 Armature。

![](IMG-20250630133724753.png)

### 修改贴图

插件对于过于复杂的贴图的处理会出错，因此建议将模型导回到 Blender 内进行二次处理。

插件能支持的贴图仅包括 base color+alpha，metallic+roughness，normal map 三张贴图，并且其中 metallic+roughness 必须是绿通道输出粗糙度、蓝通道输出金属度。对于从原始贴图需要经过多个节点计算才连接到输出的情况，可以看下文的第三节：烘焙等效贴图。

除此以外，进行材质重新处理时建议把不透明物体的 alpha 连接直接去掉，否则导出后极大概率出现奇怪的透明面。并且需要注意，使用非 MToon 着色器（例如 Blender 自己的 bsdf 着色器）后得到的模型是非标准 vrm 模型，将无法在严格校验模型的软件内使用（比如 Mate Engine 和 VRMLiveViewer），但可以在 warudo 一类会用备用着色器兼容的软件中运行。

## 二、转 pmx 模型（用于 mmd 的格式）

这个操作虽然只需要 MMD Tools 插件即可，但推荐直接安装 cats 插件，它捆绑了 MMD Tools 并且有其他一系列可以简化模型处理（尤其是迁移到 VRchat 时候需要的）的功能，并且和单独安装的  MMD Tools 可能有冲突。

需要提醒的是，官方的 cats 插件已经停更许久，并且有违反开源守则进行收费的行为。目前推荐的是 neoneko 团队重新开发的新 cats 插件，需要在 [github仓库](https://github.com/teamneoneko/Cats-Blender-Plugin-Unofficial-) 或者 [官网](https://cats.neoneko.xyz/) 下载安装。**不要为了能使用原版 cats 而降级 Blender ，这是没有价值的行为。**

在转换之前与前文的 vrm 模型一样，如果模型的不同部分分别有不同的骨骼，需要先手动将它们合并到同一个骨骼上。满足这一要求后，选中要转换的 Armature，打开 MMD Tools 面板，点击转换模型。

#### 重新烘焙等效贴图

以从街霸6的 nrrc 贴图中分离法线贴图为例（关于街霸6的 nrrc 贴图到法线贴图的相关计算在《街霸 6 Mod 制作》系列第三篇中有详细说明，这里不做赘述）。

首先新建一个纹理贴图。（UV 编辑-图像-新建）

![](IMG-20250621230924273.png)

转到着色窗口，选中与想要导出的材质相关联的网格体，在下方看到材质树。由于我此处是想将已经计算好的法线贴图本身的图像内容直接导出，所以将其直接连接到基础色上。

在材质树中新建图像纹理节点，选择刚刚新建的纹理图片，并且选中该节点。

![](IMG-20250621231120763.png)

回到布局页面，进行烘焙。渲染引擎切换到 Cycles，烘焙类型选择漫射，贡献仅保留**颜色**，然后点击**烘焙**。

![](IMG-20250621231445411.png)

烘焙完成后，再次回到 UV 编辑窗口，可以看到已经烘焙成功，将图像另存为即可导出。

![](IMG-20250630145245501.png)

补充：烘焙的时候不会保留 UV 外的部分，因此像上文这样直接在模型上烘焙，只有 UV 内的贴图。如果想要整张贴图全部保留纹理，可以添加-网格-平面，在方形的面片上烘焙。

## 四、转 stl 模型（用于 3D 打印）

众所周知，游戏模型和用于 3D 打印的模型可以说是完全相反的方向。前者追求模型的低面数，用贴图和计算来实现视觉效果，模型都是面片，并且内部可以有穿插；后者的精度上限则直接取决于模型的精细度，并且物体必须要有厚度，内部不能存在空腔。

但如果就想打个小东西玩玩，对模型也不要求高精度的还原的话，我们也可以尝试从低模和贴图中还原个大差不差的中模。

#### 原理解释

这部分非必要观看内容，只想快点做东西的人可以跳到下文的**操作步骤**章节。

常用于制作物体表面效果的贴图有：法线贴图(normal map)，高度图 (height map)，置换图(displacement map)。

其中法线贴图和高度图都属于凹凸贴图(bump map)，不改变网格顶点。前者通过保存光照法线并还原光照计算来实现视觉效果，后者通过读取该位置的高度来判断此处是凹或者凸。而置换图将会根据贴图移动顶点，真实改变模型几何形状。不难看出，我们想要的用于打印的模型就是这种被改变了实际几何形状的模型。

而虽然原理不同，但是置换图与高度图都是通过单一通道来保存信息的，并且两者的信息十分相似。所以我们可以从法线贴图出提取出高度图，再将其作为置换图应用到模型上。

#### 操作步骤

1. 下载并安装 [Materialize](http://boundingboxsoftware.com/materialize/downloads.php)（确保安装路径不要有中文）
2. 载入法线贴图
3. 转换高度图，建议将参数拉至最高，其他的保持默认
4. 保存高度图
5. 回到 3D 软件，添加曲面细分与置换修改器，置换效果器的方向改为**按 UV** ，调整效果到满意为止（置换图在本身有足够的曲面时效果才好，所以一定要先进行曲面细分）
6. 导出为 stl 模型，完成打印前的检查步骤（切片、加支撑）
